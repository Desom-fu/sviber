# sviber

[English](README.md)

sviber 是面向 [Sunniesnow](https://sunniesnow.github.io/game-unstable) 的浏览器与 NW.js 谱面编辑器。它支持编辑点按、长押、拖键、划键、背景音符、大字、全部背景图案和嵌套分组事件，并提供基于拍的定时、引导点、可复用吸附器、片段、历史记录、波形导航、实时托管，以及与 Sunniesnow 一致的预览外观。

## 在浏览器中运行

需要当前版本的 Node.js、npm，以及现代浏览器。完整的工程文件夹流程需要支持 File System Access API 的 Chromium 内核浏览器；不支持该 API 时请使用 NW.js 桌面版。

```powershell
cd sviber
npm ci
npm start
```

打开 <http://127.0.0.1:4173/sviber/>。不要直接双击 `index.html`：JavaScript 模块、依赖加载和 Service Worker 都需要 HTTP 来源。

网页首次打开时必须联网，让 Service Worker 缓存 sviber、字体和 CDN 依赖；安装完成后，之后可以离线打开。剪贴板导入/导出需要浏览器授予剪贴板权限。打开和保存工程时，需要授予所选文件夹的读写权限。

## 构建桌面版

```powershell
cd sviber
npm ci
npm run build
```

Windows 下运行 `build/nw/sviber.exe`。首次构建需要联网下载 NW.js 和固定版本的字体资源；构建完成后，程序使用本地 npm 依赖和打包字体，可以完全离线运行。发行包同时包含仓库许可证和打包字体许可证。分发时只需打包完整的 `build/nw` 目录，开发用的 `sviber/node_modules` 不需要发送；但不能删除 `build/nw/package.nw/sviber/node_modules`，并且必须把 `sviber.exe` 与同目录的全部运行库文件一起保留。

## 工程使用流程

1. 选择“**文件 > 新建工程...**”，填写第一个难度的元数据、拍 0 对应的音频时间（偏移）和初始 BPM。新工程起初只存在于内存中；第一次选择“**文件 > 保存工程**”时需要选择工程文件夹，之后保存会写回该文件夹。
2. 通过“**文件 > 设置音乐...**”和“**设置背景...**”载入所有难度共用的音乐和可选封面/背景。保存工程时，这些资源会复制到工程文件夹根目录。
3. 使用顶部难度选择器切换当前编辑的难度；使用“**文件 > 新建谱面...**”新建难度，使用“**文件 > 删除谱面...**”删除当前难度。选择器本身只有下拉选项，没有额外操作按钮。每个难度都有独立的撤销/重做历史，切换回来时会恢复；工程必须至少保留一个难度。
4. 使用波形、鼠标滚轮及时间线上的绿色/黄色控制线导航。双击紫色 BPM 数字可编辑该变速点；左侧滚动视图用于观察事件的时间与 x 坐标关系，不会修改谱面，主编辑区边缘按钮可以在需要宽度时隐藏辅助视图。
5. 没有选中非背景图案事件时，选择事件工具并在主编辑区点击即可放置音符；已有事件被选中时，选择事件工具会转换这些事件的类型。再次点击已选事件会取消选择；再次点击当前 Tap、Hold、Drag、Flick 或背景音符工具会退出创建模式。
6. 从“**吸附器**”菜单创建网格或曲线，激活后使用“**附着**”，把选中的可定位事件附着到最近的有效吸附点。
7. 在检查器中批量编辑公共属性或事件专有属性；在时间线上调整拍位/通道，在主编辑区调整空间位置。
8. 音符使用 Sunniesnow 的默认显示大小，并随主编辑区尺寸自动缩放。默认情况下，可定位事件被限制在 `x = -100..100、y = -50..50`，粘贴音符和编辑吸附器而间接移动的音符也遵循该限制；勾选状态栏的“**允许事件超界**”后，创建、粘贴、拖动、检查器编辑、变换和附着都可以越过该范围，边界线仍会保留为参考。
9. 按空格键播放预览，可查看 Sunniesnow 风格的音符音效、命中特效、事件外观、引导点和 HUD。可选的节拍器每拍播放相同的合成点击音，不区分强拍和弱拍，响度跟随偏好设置中的音效音量。
10. 选择“**文件 > 保存工程**”保存工程清单、共享媒体以及全部难度的可编辑 JSON；选择“**文件 > 导出 Sunniesnow 关卡...**”把全部难度打包到一个 `.ssc`，导出前必须设置工程音乐。

要迁移旧文件，可选择“**文件 > 导入谱面/关卡文件...**”导入旧版 Sviber JSON、普通 Sunniesnow JSON 或 `.ssc`。`.ssc` 会让你选择其中一个谱面、音乐和图片；导入结果是当前工程中的单个难度，之后使用“保存工程”把它保存到工程文件夹。

时间线支持框选；普通点击已选事件会取消选择，`Ctrl` 用于追加选择或在拖动时复制，`Alt` 用于从选择中移除，`Shift` 用于按时间和通道范围选择。主编辑区和滚动视图也支持相同的点击取消与选择修饰键。再次点击当前 Tap、Hold、Drag、Flick 或背景音符工具会退出创建模式。播放期间大部分创建和编辑命令会锁定，但“音乐”菜单命令仍可使用。

时间轴可见范围和通道垂直滚动位置属于可编辑谱面状态，打开保存的谱面时会恢复；滚动位置保存为 `sviber.editor.timelineChannelOffset`。`Ctrl`+滚轮缩放范围，`Shift`+滚轮滚动通道，`PageUp`/`PageDown` 按一个范围翻页。勾选“锁定可见范围”后，播放和普通寻拍不会移动范围，但滚动条、`Ctrl`+滚轮和范围键盘命令仍可用。按住 `Shift` 拖动事件时，移动上下文固定为最后选中的事件，不会误点到指针下的其他事件。

要用一个 Sunniesnow 引导点一次连接多个音符，请在同一频道中选择至少两个连续音符，然后在检查器中选择“**连接**”。Sviber 会把首个音符设为路径起点，让其余选中音符继承同一路径，并在下一个未选音符前自动截断。

## v12 编辑流程

分组是递归的、仅供编辑器使用的容器。“**事件 > 分组**”会分离选中事件，并以选中可移动事件的几何中心创建带颜色的 group 锚点；选中 group 后，移动、变换、删除、通道移动和导出都会递归作用于其子事件。“**事件 > 解组**”会把选中 group 的子事件放回同一层。嵌套 group 保留独立 ID 和边界。普通点击分组内事件会选中最近的直接父 group；双击会逐层进入临时选择作用域，嵌套 group 必须从外到内进入；作用域内没有选中后代时自动退出。拖动十字锚点只移动选中 group 的锚点，子事件位置保持不变；锚点可以吸附到直接子事件或启用的吸附器。

时间轴、主编辑区和滚动视图都会绘制分组圈，选中的 group 会绘制同色边界框。状态栏可以分别隐藏时间轴分组圈、主编辑区分组圈和 Tip point。这些显示设置保存在可编辑谱面中，不改变生成的 Sunniesnow 事件；导出时会递归展开 group。

复制选中事件时会保存相对拍位/通道、通道属性、引用的吸附器和嵌套 group 树。“**编辑 > 保存到片段**”会把相同数据保存到谱面的片段面板。片段可重命名、排序、删除，并在当前拍位和通道粘贴。“**编辑 > 带选项粘贴...**”可以复制引用的通道和/或吸附器，嵌套 group 内的引用也会递归映射；普通粘贴会尽可能复用现有通道和吸附器。

“**定时**”菜单可以编辑偏移和初始 BPM，也可以把完整定时表复制为 JSON 或从 JSON 粘贴。定时数据与事件剪贴板相互独立。事件剪贴板还包括带相对位置的通道和吸附器记录，供“带选项粘贴”复制引用。时间轴通道滚动条位置会保存到 `sviber.editor.timelineChannelOffset`，重新加载谱面时恢复显示。在 NW.js 中启用实时托管后，`http://主机:端口/sviber.ssc` 会提供内存中的关卡包，可选的 sscharter WebSocket 端口会发送 `connect`、`update` 和 `chartUpdate` 消息。实时导出包含 `sscharter.version = "0.10.1"`；浏览器版本会禁用服务器控件。

自由变换不能从宽度或高度为零的边界框启动。十字锚点初始位于边界框中心，可吸附到事件、边界框角点/边缘中心/中心、启用吸附器的吸附点或自由位置；内容锚点随变换移动，自由或吸附器锚点保持固定。按住 `Ctrl` 拖角点保持宽高比，按住 `Shift` 拖角点或边缘手柄以锚点为固定点，按住 `Ctrl` 旋转吸附到 `pi/4` 的整数倍。除角点外还提供四个边缘手柄。

## 工程文件夹与关卡格式

已保存的工程使用扁平的根目录结构。资源名和难度文件名可以不同，基本结构如下：

```text
我的工程/
|-- sviber-project.json
|-- song.ogg
|-- cover.png
|-- easy.json
`-- master.json
```

- `sviber-project.json` 是工程清单，记录共享音乐、可选封面/背景、全部难度 JSON 以及当前难度。选择“**文件 > 打开工程文件夹...**”后，sviber 会读取该清单，自动载入其中列出的所有难度和共享媒体。
- 歌曲标题、艺术家、音乐和封面/背景属于工程共享字段；难度名、难度颜色、等级、谱师、定时、事件和撤销/重做历史按难度分别保存。
- 工程根目录中的每个难度 JSON 都是可继续编辑的 sviber 文档。它在 Sunniesnow Chart 1.0 顶层增加 `sviber` 对象，用于保存基于拍的定时、通道、吸附器和编辑器设置等制谱数据。顶层 `events` 会重新生成以保持兼容，但重新打开工程时会以 `sviber` 内的可编辑数据为准。可编辑数据还可以包含递归 `group` 事件和 `clips` 数组；group 子事件保留稳定的递归 ID，导出时会递归展开，片段保存相对事件树及其通道和吸附器记录。
- “允许音符超界”按难度保存在 `sviber.editor.allowOutOfBound` 中；切换它可以撤销/重做，并会把该难度标记为已修改。导入旧谱面时仍兼容 `allowOutOfBounds` 拼写。
- 导出的 `.ssc` 是交给 Sunniesnow 的 ZIP 关卡包，不是可编辑工程的副本。压缩包根目录包含共享音乐、可选封面/背景，以及每个难度各一份纯 Sunniesnow Chart 1.0 JSON；其中不含 `sviber-project.json`，正式难度 JSON 顶层也不含 `sviber` 扩展。所有条目都位于压缩包根目录，因为目标 Sunniesnow 版本只会在那里发现关卡音乐、图片和难度 JSON。
- 导出时会按 sviber 支持的 Sunniesnow Chart 1.0 子集严格验证每个难度。必填元数据不能为空，且至少要有一个事件；编辑器专用数据不会写入正式谱面 JSON。

编辑器默认每 120 秒把当前有未保存修改的难度写入一次 `localStorage`。“**文件 > 偏好设置...**”可以修改间隔，设为 `0` 可关闭自动保存。如果自动保存比最后一次手动保存更新，下次启动时会提供恢复选择；旧记录会保留，直到存储空间不足时才淘汰。自动保存为了节省空间和时间不写入生成的顶层 `events` 列表，普通保存仍会写入。界面语言跟随浏览器：中文区域使用 `zh-CN`，其他区域使用 `en-US`；英文界面显示 **English** 和 **Simplified Chinese**，中文界面显示 **英文** 和 **简体中文**。编辑器、宏页面和手册页面共享明确选择的浅色/深色主题；选择跟随系统时才使用系统主题。

状态面板使用只有图标的控制项，依次用于锁定可见范围、音符音效、播放后返回、恒定响度节拍器、只读和全屏。只读模式仍允许选择事件、寻拍、调整范围、“音乐”菜单、编辑注释、切换难度以及启用/停用通道和吸附器，但会阻止其他谱面、吸附器、通道、宏和历史修改。即使弹窗表单处于打开状态，`F11` 也能切换全屏；`Esc` 不会退出全屏。难度下拉框获得焦点时，全局数字键和空格键快捷键仍然有效。时间轴引导线只连接同一引导中实际可见的相邻事件，滚动视图的时间比例与时间轴保持一致。网页版本可安装为 PWA，Service Worker 也会缓存 JSON 翻译文件。

## 宏与发行包

独立的“**宏**”窗口支持 JavaScript 和 Ruby 全局宏。在 NW.js 中，工程宏是工程文件夹中的 `.js` 或 `.rb` 文件。两种 API 都可以读写元数据、编辑器状态、定时、通道、事件、吸附器和选择，并提供查找/修改/删除辅助函数。JavaScript 控制台输出以及 Ruby 的 `$stdout`/`$stderr`（包括 `puts`、`print` 和 `warn`）都会显示在宏控制台；成功运行会作为一条可撤销的谱面修改应用。

发行构建按架构分别打包：Windows 提供 x86、x86_64 和 aarch64 ZIP，macOS 提供 x86_64 和 aarch64 ZIP，Linux 提供 x86_64 和 aarch64 的 `tar.gz`；另外会生成不含 NW.js 运行时的 `.nw` 包。

## 分享源码或桌面构建

分享开发源码时可以删除 `sviber/node_modules`；接收方进入 `sviber` 目录运行 `npm ci`，即可根据 `package-lock.json` 恢复固定版本的依赖。已经构建好的桌面包中，不能删除 `build/nw/package.nw/sviber/node_modules`。请分发完整的 `build/nw` 目录，包括 `sviber.exe` 和同目录的全部运行库文件。

## 开发与验收

```powershell
npm test
npm run verify:browser
npm run build
```

`verify:browser` 默认使用 `http://127.0.0.1:4173/sviber/`；如果该地址不可用，会自动启动并在结束时清理临时本地服务器，也可以用 `SVIBER_BASE_URL` 覆盖地址。它会检查中英文界面、明暗主题、960x620 最小窗口、响应式 Sunniesnow 音符大小、限界/超界的全部编辑路径、真实指针交互、Canvas 非空以及离线重载。

项目采用仓库根目录中的许可证。第三方 JavaScript 包和字体仍遵循各自许可证；桌面构建会包含下载字体对应的许可证文件。
