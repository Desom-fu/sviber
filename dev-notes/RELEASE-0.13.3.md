# Release 0.13.3

本版本修复时间轴总览滚动条和主编辑区 HUD 进度条的鼠标交互：

- 点击总览滚动条绿色可见范围之外的空白轨道，会按点击方向将可见范围翻动一个可见跨度；当前时间原本在范围内时同步移动，否则保持不变。
- 按住 Ctrl 点击或拖动总览滚动条，会把当前时间定位到指针位置并吸附到当前细分；当前时间原本在范围内时，可见范围保持其视觉位置。
- 主编辑区 HUD 底部进度条注册稳定的低优先级命中区域，支持点击和拖动寻拍；事件、吸附器和暂停按钮命中仍优先。
- 中英文用户手册同步说明上述交互。
