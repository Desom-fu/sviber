sviber

sviber User Manual

sviber is a desktop-style editor for Sunniesnow charts. A chart contains timing, events, channels, snappees, comments, media references, and editor state. Saving a chart keeps the editable data; exporting a level produces Sunniesnow-compatible chart data. The web version is an installable PWA and caches its application shell and translations for offline startup.

Start Here

Projects, charts, and files

In NW.js, File > New project... and Open project folder... manage a folder with a project manifest, one JSON file per difficulty, and shared music/background files. A browser opens one JSON chart at a time and saves it with a download. Project-only commands are unavailable in a browser. New chart... asks about unsaved changes before replacing the current chart.

Save writes the editable chart, while Save as... chooses a new file. Save project writes every difficulty and shared asset. Export level... creates a Sunniesnow level package. Export Lyrica chart... writes a Lyrica .txt file directly, without a Sunniesnow chart or placeholder events as a medium. Clipboard commands use the editable sviber JSON; Import chart/level file... accepts editable JSON, plain Sunniesnow JSON, a level package, or a Lyrica chart (.txt). After a Lyrica file is chosen, a form collects Charter, PRNG seed, and Quantization denominator.

Difficulties and new charts

The NW.js toolbar has a difficulty selector. Each option is shown as difficulty name rating superscript; the difficulty name uses its configured color. Switching difficulties asks whether to save pending changes. The selector is not shown in the browser, where only one chart is open. A new chart starts with an active rectangular Playfield grid from (-100,50) to (100,-50), divided into 16 by 8 tiles. Other preset snappees can be added later.

Music and timing

Set music from File > Set music.... The offset is the audio time of beat zero; the initial BPM and ordered BPM changes convert beat positions to seconds. Beat zero can be before or after the audio beginning. Opening a saved chart restores its saved current time, subdivision, and visible timeline range.

Saving and recovery

By default, a dirty chart is saved to the local recovery list every 120 seconds. The interval is configurable; zero disables autosave. Startup offers every recovery newer than the last manual save before reopening the last document. In NW.js, restoring a recovery also restores its project and chart path context, then reloads relative music and background references automatically. Autosave records omit the generated top-level event list to reduce storage; ordinary chart and project saves include it. History entries distinguish manual saves from autosaves.

Workspace

Layout and panel buttons

The workspace has a menu bar, toolbar, timeline, status panel, scroll view, main editor field, side panels, history, and a tooltip bar. Hover near the left edge of the main editor field to reveal a DOM button that hides or shows the scroll view. Hover near the right edge to reveal a button that hides or shows the Inspector, Channels, Snappees, Clips, and History panels together. Neither group is hidden by default; hiding either group gives the main field more width.

Timeline anatomy

The timeline contains a waveform, beat lines, channel lanes, and a horizontal overview scrollbar. The yellow line is current time. Green end handles change the visible range; the green middle bar moves both ends. The current time may be outside the visible range. On the scrollbar, the yellow current-time line has priority over the green handles and bar; blue A-B marks are indicators only and cannot be dragged. Hold Ctrl+Space while dragging to pan the visible range without changing current time, even when locked.

Clicking a lane seeks to its time and makes that lane current. Clicking and dragging on an empty lane makes a live rectangular selection; a three-pixel movement threshold keeps a click from becoming a drag. Ctrl adds to selection and Alt removes from selection. Shift-click or Shift-drag selects an inclusive channel range and a time range whose end is exclusive. Dragging an event moves it in time; dragging its white duration handle changes its end time. The vertical channel-scroll position is saved in sviber.editor.timelineChannelOffset and restored when the chart is loaded. Timeline and stage drags are coalesced to animation frames; their lightweight previews update the canvases and status only, while panels and history are refreshed when the gesture ends.

Ordinary wheel movement seeks by one subdivision. Ctrl+wheel zooms the visible range without changing its center; Shift+wheel scrolls channel lanes even when the pointer is outside the timeline canvas, unless the pointer is in a scrollable DOM element. Clicking outside the range bar pages the range by one span. PageUp shifts the range toward negative time and PageDown toward positive time. When a channel is selected with Alt+Up/Down or Alt+1..9/Alt+0, the lane scrollbar follows it when needed and event-creation mode stays active. Number and Space shortcuts remain active when a status checkbox or the difficulty selector has focus.

Waveform and beat lines

Click or drag the waveform to seek. Beat-line positions and colors are relative to the latest bar line, while each red line is labeled with its absolute beat number; fractional labels use integer-plus-fraction notation and bar lines are thick red lines. Press R to add or remove one at the current time; snapping and the metronome follow these relative beats. One A-B mark is a bright blue line. Two marks add a translucent blue interval and two blue lines even when the subdivision differs. BPM changes are shown as purple numbers. Seeking while stopped snaps to the nearest subdivision except when a command explicitly requests an exact time.

Status panel

The status panel has no title. It shows time to three decimal places, the current beat using the current subdivision denominator, playback speed, comments active at the current time, and the current operation. A selected comment is red here; other comments use the normal text color. Its icon controls have no visible text labels. Background-event icons independently hide/show bg notes, big text, and background patterns in the timeline/scroll view or main field.

  • Lock visible range: playback, reverse playback, and menu/mouse-wheel seeking do not follow or resize the range. The scrollbar, Ctrl+wheel, and keyboard range commands remain usable.
  • SE: globally enables note hit sounds. Events in inactive channels are always silent.
  • Seek back after playing: restores the time and visible range captured when playback began.
  • Metronome: plays one sharp, short synthesized click whenever the time is an integer number of beats from the latest bar line. Every click uses the same sound and level; there is no strong-beat/weak-beat accent. Its level follows the Preferences SE volume.
  • Rulers (rulers.svg): off by default. When checked, top and left rulers appear in the main field. The scale inside the chart bounds is white; the scale outside is light gray; ticks and numbers are dark gray. A very noticeable triangle marker follows the mouse. Major and minor ticks change with main-field zoom.
  • Read-only: keeps event selection, time/range navigation, Music commands, comments, difficulty selection, and channel/snappee activation available while disabling other chart, snappee, channel, history, and macro mutations. The macro window remains available; global macros stay editable, project macros become read-only, and no macro can run.
  • Fullscreen: enters or leaves fullscreen. F11 toggles it even while a popup form is active, and the checkbox follows fullscreen changes made by the runtime. In NW.js, Esc does not leave fullscreen.

Main editor field

The main field previews the chart at the current time. Group rings around notes are larger than the note body. Events attached to the selected snappee in an active channel also get a same-rule circle in that snappee's color. Background patterns and big text are not selected by clicking their preview; select them from the timeline or Channels panel. Click an event to select it without changing time; click a selected event again to clear it; Ctrl-click adds it and Alt-click removes it. Selected objects remain visibly marked even when outside the current preview time. Inactive channels and their tip points are hidden and cannot be selected.

The HUD copies Sunniesnow's layout, including the top-left title and pause button. Clicking the pause button runs the same action as play/pause and loses to event or snappee hits.

Manual search keeps the full manual visible and jumps to the first matching paragraph, list item, or table row as you type. Press Enter to move downward to the next match, or Shift+Enter to move upward; navigation wraps at the end.

Drag a movable event to change position. A single event can attach automatically to the nearest active snap point; attached events can be moved according to their snappee type. Shift-drag moves the current selection without requiring the pointer to hit one selected event and without retargeting another event. If no movable event is selected, the same gesture moves the selected snappee; any of its snap points can align to a nearby point on another active snappee. Escape cancels a free transform. Enter applies it when the inspector is not editing a field; in a matrix field, Enter submits that element instead of confirming free transform. The inspector matrix numbers update live. Translating, scaling, or rotating past the chart boundary clamps so the would-be out-of-bound event lands exactly on the boundary.

Groups, clips, timing, and live hosting

Events > Group creates a recursive group with a colored anchor at the selected movable events' center. Group selection applies to descendants for movement, transforms, deletion, channel operations, and export; an attached group can still be moved when it is the only selected root. Ungroup restores children at the same level. Group rings appear in the timeline, main field, and Scroll view, and a selected group has a colored bounds rectangle in all three views. The crosshair anchor for a selected group appears only in the main editor field. Dragging it moves the selected group anchors while leaving children in place; anchors can snap to direct children or active snappees.

A group stores no time or channel; its displayed time is derived from its earliest descendant. A normal click on a grouped event selects its nearest parent group, and clicking that selected group again clears it. Double-click enters one group level temporarily; nested groups are entered from the outside inward, and the scope exits when it has no selected descendants.

Save to clips stores the relative event tree, channel attributes, and referenced snappees in the Clips panel. Each row separates its 42px thumbnail, name, and five actions with clear spacing. Clips can be pasted, renamed, reordered, or deleted. Paste with options... can duplicate referenced channels and/or snappees, including references nested in groups. The Timing menu edits offset and initial BPM and copies or pastes the complete timing map independently from event clipboard data. In NW.js, Live hosting serves an in-memory sviber.ssc over HTTP and can publish sscharter WebSocket updates; live JSON has sscharter.version = 0.10.1. Browser builds do not start these servers.

Scroll view

The scroll view is to the left of the main field. Horizontal position is chart x; vertical position is time, with later time higher. The current-time line stays three quarters of the way down from the top, exactly one quarter of the panel height from the bottom, while events move through it. Hold and background-note durations have vertical tails. Inactive-channel events are hidden. Background-note icons are drawn below other event icons; among other icons, later times are drawn above earlier times. Tip-point chains use a translucent white connector, and a thin dark-yellow segment at the first event shows the spawn direction. Each connector is drawn only for an adjacent pair in the same guide with at least one visible endpoint, so unrelated off-screen notes cannot create a full-width line.

The scroll view uses the same pixels-per-second scale vertically as the timeline uses horizontally. Its x-range is Sunniesnow's default play-field width (250). Its visible time span can therefore extend beyond the music. Horizontal beat lines use the timeline colors, the current time is a bright yellow line, and red labels mark integer beats. A-B loop marks draw bright blue horizontal lines; when both marks exist a translucent blue band covers the interval. Group rings and selected-group bounds remain visible, but group anchors are not drawn or hit-tested here. Click an icon to select it; Ctrl adds and Alt removes. Drag on empty space to box-select by event centers. The scroll view never edits event positions or times.

Inspector, Channels, Snappees, and History

The Inspector shows common properties of the selected events and shows a gray message when nothing is selected. Its channel dropdown lists channel names rather than numbers. For a group it shows the read-only time derived from the earliest descendant and an editable color, but no event type or channel field. Channels can be activated, duplicated, reordered, renamed from the right-side Channels panel, edited, or deleted; deactivating a channel deselects its events and prevents their preview and sound. Snappees can be activated, duplicated, reordered, edited, or deleted; deleting one detaches its events while keeping their resolved positions. Double-clicking a row opens its edit form. History stores up to 1000 changes and marks manual and automatic saves separately. Existing history labels, including Group and Ungroup, are translated again immediately when the interface language changes.

Editing Details

Creation, snapping, and selection

Creation tools remain active after each placement; clicking the active Tap, Hold, Drag, Flick, or background-note tool again exits that mode. Timeline interaction does not exit creation mode, although events cannot be created while playback is running. Hold and background-note duration defaults remember the last value used for that type. Snap-to-point uses a chart-coordinate distance threshold of 6.25. During creation and attachment, points outside the chart boundary are rejected; only a tiny numeric tolerance is used for points that should mathematically lie exactly on the boundary. Other in/out-of-bounds checks have no tolerance. For an open Pen or Bézier curve, the segment count is the number of intervals, so three segments have four snap points including both endpoints; a closed curve has one snap point per segment.

Timeline and stage dragging use a three-pixel pointer threshold. Hold Ctrl+Space while dragging the timeline or scroll view to pan visible time; hold it in the main field to pan chart space. Hold Ctrl+Shift and use the wheel anywhere in the editor to zoom the main field; ordinary Ctrl+wheel on the timeline still zooms its visible time range. The reset button restores the default view. Clicking the main-field progress bar seeks with lower priority than event and snappee hits. A selected movable event may move freely when it is the only movable event, even if it is attached; multiple attached events move together only when their attachment rules allow it. Shift-dragging uses the last selected event as the movement context, so another event under the pointer cannot be selected accidentally. Inactive channels cannot be selected, made current, or dragged into.

Free transform cannot start when an ordinary event selection has transformed bounds with zero width or height. A selected group uses a one-unit minimum fallback for a zero-width or zero-height axis, so a line-shaped group can still rotate, scale, and translate. Its crosshair anchor initially sits at the bounds center and can be dragged to an event, a bounds corner, an edge center, the bounds center, an active snappee point, or a free position. Anchors snapped to transformed content follow the transform; free or snappee anchors stay fixed. Corner scaling with Ctrl preserves aspect ratio. Corner or edge scaling with Shift uses the anchor as the fixed point, and rotation with Ctrl snaps to multiples of pi/4. Four edge handles are available in addition to the corner handles. Translating, scaling, or rotating past the chart boundary clamps so the event that would leave lands exactly on the boundary. Enter in a matrix inspector field submits that element instead of finishing the transform.

Channels and snappees

Channel rows provide visibility, duplicate, reorder, edit, and delete actions; the channel menu no longer contains a duplicate Rename command, so renaming is available from the right-side row action or by double-clicking that row. Snappee rows provide activate/deactivate, duplicate, reorder, edit, and delete actions. Snappee edit forms include name, color, type-specific parameters, and a six-number transformation matrix laid out as the CSS/Canvas 2×3 form a c tx / b d ty. Matrix changes move attached event positions, flick directions, and tip-point spawn positions consistently. A selected snappee can be translated or transformed even when no events are selected.

Tip-point inspector

inherit continues the previous guide, chain starts a guide, drop starts a one-event guide, and none stops a guide. Spawn position can be absolute or relative; spawn time can be seconds or beats. Inherit and none hide every tip-point field except spawn type. Switching inherit to chain or drop fills inherited spawn params if any, otherwise defaults. Only chain and drop enable these controls. Absolute mode shows coordinates (and attachment when a snappee exists); relative mode shows distance and direction; unused fields are hidden. Relative direction is stored in radians and is entered in degrees unless the radians option is selected. Only tap, hold, drag, and flick are tip-pointable in sviber; background notes are not.

Sunniesnow tip-point import

Import filters incompatible records from each tipPoint chain without deleting those events from the chart, adds and trims placeholders, chooses the first channel free for the chain interval (creating one when needed), and assigns drop or chain/inherit modes. It derives the first event's relative spawn distance, direction, and time from the placeholder. Events with no tip point go to the first channel with mode none.

Playback

Forward and reverse playback

Forward playback follows the chart timing and plays music, note sounds, hit effects, and the constant-tone metronome when enabled. Hit effects disappear immediately when the music stops. Reverse playback moves time backward, leaves music muted, and can still play note sounds and metronome clicks; it does not play hit effects. Inactive channels never contribute to playback.

A-B looping

With two marks, the earlier mark is A and the later mark is B. Forward playback returns to A at B without an audible gap; reverse playback returns to B at A. Boundary notes and metronome clicks are scheduled once per pass. If a loop jump leaves the visible range, the range moves by the minimum amount unless it is locked.

Playback settings and seeking

Seeking while playing pauses only for the interaction and resumes in the same direction. Changing the visible range never interrupts playback. When playback ends or is paused, time snaps to the nearest subdivision unless Seek back after playing is enabled, in which case the captured time and visible range are restored. Lock visible range prevents follow mode and menu/mouse-wheel seeking from moving the range, but not scrollbar, Ctrl+wheel, or keyboard range commands.

Toasts and asynchronous actions

File, media, clipboard, autosave, and live-hosting operations report success or failure in stacked bottom-right toasts. Live-hosting startup includes the host, HTTP port, and reload port; stopping and errors are also reported.

Macros Interface

Lists and tabs

The macro window has File, Edit, and Run menus, Global and Project lists, an editor tab strip, and a console. A macro is JavaScript or Ruby. Global macros are stored by sviber; project macros are .js or .rb files in the open NW.js project directory. The Project list is unavailable in a browser or without an open project. An asterisk means unsaved editor text; closing a dirty tab asks before discarding it. While the main editor is read-only, global macros remain editable, project editing controls are disabled, and both F8 and Run are disabled. The sandbox loads its JavaScript/Ruby APIs from separate source files and has no filesystem access.

Macro API

API names are available directly at the top level of a macro. JavaScript uses camelCase and Ruby uses snake_case; there is no API container or raw chart object. Every collection below contains live wrappers for the sandboxed chart copy. JavaScript beat arguments accept a number, [numerator, denominator], or a file-format [whole, numerator, denominator] tuple. Ruby beat arguments accept only Integer and Rational. Angles accept radians or direction names: right/r is 0, up/u is pi/2, left/l is pi, and down/d is -pi/2. JavaScript combined names use camelCase (upLeft/leftUp) while Ruby uses symbols (:up_left/:left_up); both languages also accept ul/lu and the corresponding diagonal aliases. Colors accept a hexadecimal integer or CSS color and are normalized.

Events and clips

Data and Preferences

Editor fields

The editable editor state stores time snapping, subdivision, current time/channel, visible range, timeline channel offset, playback speed, per-difficulty allowOutOfBound, grouping/background/tip-point/rulers display toggles, mainFieldPanX, mainFieldPanY, mainFieldZoom, lockVisibleRange, playSe, seekBackAfterPlaying, metronome, readOnly, and zero, one, or two rational abLoopMarks. The timing object stores barLines alongside BPM changes. Rational inputs use integer + numerator/denominator controls. Validation waits until focus leaves the complete group. A positive denominator is required; numerator and denominator that are not coprime are accepted and automatically reduced.

Preferences, language, and appearance

Preferences are global and do not create chart history. They include Light, Dark, or System theme; interface language; note speed; SE volume; music volume; live-hosting address and reload port in NW.js; and autosave interval in seconds. SE and music volume default to 1 and are edited with a range slider plus a numeric output. The default autosave interval is 120 seconds, and zero disables it. Each language selector uses its current interface language: English shows Simplified Chinese, while Chinese shows 简体中文; the English choice remains English.

The main editor, macro page (including the console), and manual share the saved theme. Explicit Dark or Light always wins; System follows the operating-system color preference. Extra undocumented functions or classes in the macro sandbox are not user-facing. The language choice is remembered separately for the manual. Changing the editor language also updates existing history labels and the JavaScript license link in the footer immediately. The web editor can be installed as a PWA; its Service Worker caches both JSON translation files and the icon controls.

Saved data

An editable JSON chart keeps the sviber extension with timing, channels, snappees, events, and editor state. Group records contain recursive children, position/attachment data, and color, but do not contain time or channel. A normal save also writes a generated top-level events list for Sunniesnow compatibility; inactive-channel events and editor-only comments are omitted from that generated list, and groups are flattened recursively. Autosave intentionally leaves that generated list out. Exported level charts contain only the supported Sunniesnow data.

Troubleshooting

If audio fails, reload once and check the warning area; a desktop build includes its audio decoder and can run offline after installation. If Monaco cannot load, the macro window falls back to a plain text editor. If a saved chart opens with an unexpected timeline, verify that it was saved after the desired range was set. For rendering, timing, or macro bugs, reproduce in both browser and NW.js, export the chart, and include Help > About information and import warnings in an issue.

sviber 用户手册

sviber 是 Sunniesnow 谱面的桌面式编辑器。谱面包含定时、事件、通道、吸附器、注释、媒体引用和编辑器状态；保存会保留可编辑数据，导出关卡时才生成 Sunniesnow 可用的谱面数据。网页版本可以安装为 PWA，Service Worker 会缓存应用外壳和翻译文件，便于离线启动。

从这里开始

工程、谱面与文件

NW.js 中，“文件 > 新建工程...”和“打开工程文件夹...”管理包含工程清单、每个难度一个 JSON 以及共享音乐/背景文件的文件夹。浏览器一次打开一个 JSON 谱面并用下载保存；浏览器不能使用工程专用命令。“新建谱面...”会先处理未保存修改，再替换当前谱面。

“保存”写入可编辑谱面，“另存为...”选择新文件；“保存工程”写入全部难度和共享资源；“导出关卡...”生成 Sunniesnow 关卡包；“导出阳春白雪谱面...”直接写出阳春白雪 .txt，不以 Sunniesnow 谱面或占位事件为中介。剪贴板命令使用可编辑 Sviber JSON；“导入谱面/关卡文件...”接受可编辑 JSON、普通 Sunniesnow JSON、关卡包或阳春白雪谱面（.txt）。选择阳春白雪文件后会询问谱师、伪随机种子和量化分母。

难度与新谱面

NW.js 工具栏有难度选择器。每个选项显示为“难度名 定级 上标”，难度名使用设置的颜色。切换难度时会询问是否保存未保存修改；浏览器不显示选择器，因为一次只打开一个谱面。新谱面默认创建并启用一个从 (-100,50) 到 (100,-50)、横向 16 格纵向 8 格的“游玩区域网格”；其他预设吸附器可稍后添加。

音乐与定时

通过“文件 > 设置音乐...”载入音频。偏移表示第零拍对应的音频时间；初始 BPM 和按顺序排列的 BPM 变化把拍位换算成秒。第零拍可以早于或晚于音频起点。打开已保存谱面时，会恢复保存时的当前时间、细分和时间轴可见范围。

保存与恢复

默认情况下，有未保存修改的谱面每 120 秒写入一次本地恢复记录。间隔可修改，设为 0 可关闭自动保存。启动时会列出所有晚于最后一次手动保存的恢复记录，然后再尝试打开上次文档。在 NW.js 中恢复记录时，还会恢复对应的工程和谱面路径上下文，并自动重新载入相对路径的音乐与背景。自动保存为了节省空间不写入生成的顶层事件列表；普通谱面保存和工程保存仍会写入。历史记录会区分手动保存和自动保存。

提示消息

文件、媒体、剪贴板、自动保存和实时托管等异步操作会在右下角以可堆叠提示消息报告成功或失败。实时托管启动提示包含主机、HTTP 端口和重载端口，停止和错误也会提示。

工作区

布局与面板按钮

工作区包含菜单栏、工具栏、时间轴、状态栏、滚动视图、主编辑区域、侧面板、历史面板和提示栏。鼠标移到主编辑区域左边缘中央会出现 DOM 按钮，用来隐藏或显示滚动视图；移到右边缘中央会出现按钮，用来同时隐藏或显示检查器、通道、吸附器和历史面板。两组面板默认显示，隐藏后主编辑区域会变宽。

时间轴结构

时间轴包含波形、拍线、通道轨道和横向总览滚动条。黄色线是当前时间；绿色两端调整可见范围，绿色中段同时平移两端；当前时间可以在可见范围外。按住 Ctrl+Space 拖动时间轴可平移可见范围，即使锁定也有效。滚动条上的黄色当前时间线优先于绿色端点和中段；蓝色 A-B 标记只是指示，不能拖动。

点击轨道会寻拍并切换当前通道；在空轨道按下并拖动会实时框选，超过 3 像素才从点击变为拖动。Ctrl 追加选择，Alt 移除选择。Shift 点击或拖动选择包含首尾通道的范围，以及起点包含、终点不包含的时间范围。拖动事件会移动拍位，拖动白色时长手柄会改变结束时间。通道垂直滚动位置保存在 sviber.editor.timelineChannelOffset，打开谱面时恢复。

普通滚轮按一个细分寻拍；Ctrl+滚轮在不改变中心的情况下缩放可见范围；Shift+滚轮即使指针不在时间轴画布上也能滚动通道，除非指针位于可滚动的 DOM 元素中。点击可见范围条外侧会按一个跨度翻页。PageUp 向负时间移动范围，PageDown 向正时间移动。用 Alt+上/下或 Alt+1..9/Alt+0 选择通道时，有需要会自动滚动通道条，且不会退出事件创建模式。状态栏图标控件或右上角难度选择器获得焦点时，数字键和空格等全局快捷键仍然有效。

波形与拍线

点击或拖动波形寻拍；拍线位置和颜色相对最近小节线计算，红色拍线旁显示绝对拍号，非整数拍号使用整数加分数格式，小节线加粗。按 R 在当前时间添加或移除小节线；吸附和节拍器都使用相对拍位。一个 A-B 标记显示亮蓝竖线；两个标记额外显示半透明蓝色区间和两条蓝线，无论当前细分如何都可见。BPM 变化以紫色数字显示。停止时寻拍通常吸附到最近细分，明确要求精确时间的命令除外。

状态栏

状态栏没有标题，显示三位小数时间、按当前细分分母显示的当前拍、播放速度、当前时间生效的注释和操作信息。注释被选中时在这里显示为红色，否则使用普通文字颜色。状态栏图标控件没有可见文字：

  • 锁定可见范围：播放、反向播放以及菜单/普通滚轮寻拍不会跟随或改变范围；滚动条、Ctrl+滚轮和键盘范围命令仍可用。
  • SE：全局启用音符打击音；停用通道始终静音。
  • 播放后返回：恢复播放开始时记录的时间和可见范围。
  • 节拍器：在相对最近小节线为整数拍的位置播放短促、清晰的合成点击音。每次点击使用相同的声音和响度，不区分强拍与弱拍；响度跟随偏好设置中的音效音量。
  • 显示时间轴背景事件：切换时间轴和滚动视图中的墨点、大字与背景图案。
  • 显示主区域背景事件：切换主编辑区中的墨点、大字与背景图案。
  • 标尺（rulers.svg）：默认关闭。勾选后主编辑区顶部和左侧显示标尺：谱面边界内为白底，边界外为浅灰，刻度与数字为深灰；鼠标处有非常醒目的三角标记，刻度随主区域缩放变化。
  • 只读：仍可选择事件、改变时间/范围、使用“音乐”菜单和操作注释，但会禁用谱面、吸附器、通道、历史和宏修改。宏窗口仍可打开；全局宏可编辑，工程宏只读，任何宏都不能运行。
  • 全屏：进入或退出全屏；即使弹窗表单打开，F11 也能切换，复选框会跟随运行时产生的全屏变化。NW.js 中 Esc 不会退出全屏。

主编辑区域

主区域按当前时间预览谱面。分组圆环大于音符本体；附着到当前选中吸附器且位于活动通道的事件会再画一圈同规则、吸附器颜色的圆。按住 Ctrl+Space 拖动可平移；鼠标位于编辑器任意位置时，按住 Ctrl+Shift 滚轮都可缩放主编辑区，时间轴普通 Ctrl+滚轮仍缩放可见时间范围。底部重置按钮恢复默认视图；点击底部进度条可寻拍。HUD 含左上角暂停按钮，动作与播放/暂停相同，优先级低于事件和吸附器命中。背景图案和大字不能通过预览选择，只能从时间轴或通道面板选择。点击事件选择而不改变时间；再次点击已选事件会取消选择；Ctrl 点击追加，Alt 点击移除。即使事件不在当前预览时间，选中标记仍会显示。停用通道及其游标不可见也不可选择。

手册搜索会保持全文显示，并在输入时自动跳到第一个匹配的段落、列表项或表格行。按 Enter 向下跳到下一个匹配，按 Shift+Enter 向上跳转，到末尾后会循环。

分组、片段、定时与实时托管

“事件 > 分组”会以选中可移动事件的中心创建带颜色的递归 group 锚点。选中 group 后，移动、变换、删除、通道操作和导出都会递归作用于子事件；附着后的 group 作为唯一选中根对象时仍可移动。“解组”会把子事件放回同一层。时间轴、主编辑区和滚动视图会显示分组圈，选中 group 会在三个视图中显示同色边界框；所选 group 的十字锚点只出现在主编辑区。拖动锚点只移动所选 group 的锚点并保持子事件位置不变，锚点可吸附到直接子事件或启用的吸附器。

Group 不保存 time 或 channel，显示时间由最早的后代事件推导。普通点击分组内事件会选中最近的父 group，再次点击这个已选 group 会取消选择；双击会逐层进入临时作用域，嵌套 group 必须从外到内进入，作用域内没有选中后代时自动退出。

“保存到片段”会把相对事件树、通道属性和引用的吸附器保存到片段面板。每行的 42px 缩略图、名称和五个操作按钮之间保留清晰间距。片段可以粘贴、重命名、排序和删除。“带选项粘贴...”可以选择是否复制引用的通道和吸附器，包括嵌套 group 中的引用。“定时”菜单独立编辑或复制/粘贴完整偏移与 BPM 数据。在 NW.js 中，实时托管通过 HTTP 提供内存中的 sviber.ssc，并可通过 sscharter WebSocket 推送更新；实时 JSON 包含 sscharter.version = 0.10.1。浏览器版本不会启动这些服务器。

拖动可移动事件改变位置；单个事件靠近启用吸附器的吸附点时会自动附着，附着事件可按吸附器类型移动。Shift 拖动会移动当前选择，不需要瞄准某个已选事件，也不会误选指针下的其他事件。没有可移动事件选择时，同一手势会移动已选吸附器；它的任意吸附点都可以对齐到其他启用吸附器附近的吸附点。拖动输入会合并到动画帧，预览期间只刷新画布和状态，检查器、历史等完整刷新在手势结束时执行。Escape 取消自由变换。未在检查器里编辑时，Enter 应用自由变换；在变换矩阵输入框里按 Enter 只提交该矩阵元素。平移或缩放超出谱面边界时会贴到边界，而不是整段拒绝。

滚动视图

滚动视图位于主编辑区左侧。横向是谱面 x 坐标，纵向是时间，较晚时间在上方。当前时间线固定在距顶部四分之三、也就是距底部正好四分之一面板高度的位置，事件相对它向上或向下移动。Hold 和墨点显示表示时长的竖直尾巴。停用通道中的事件隐藏；墨点图标总在其他事件下方，其他图标则较晚时间绘制在较早时间上方。游标链用半透明白色粗线连接，首事件旁的深黄色细线表示出现方向；每条白线只连接同一引导中相邻且至少有一个端点可见的事件，不会因屏幕外事件把整行铺满。

滚动视图的纵向每秒像素比例与时间轴的横向每秒像素比例一致，横向谱面 x 比例独立，因此可见时间范围可能超过音乐边界。按住 Ctrl+Space 拖动可通过改变当前时间平移；停止播放后会吸附到细分。水平拍线使用与时间轴相同的颜色，当前时间是亮黄色线，红色拍线左侧显示数字。分组圈和所选 group 的边界框仍会显示，但滚动视图不会绘制或命中 group 锚点。点击图标选择；Ctrl 追加，Alt 移除；在空白处拖动按事件中心框选。滚动视图不能直接编辑事件的时间或位置。

检查器、通道、吸附器与历史

检查器显示所选事件的公共属性，没有选择时会显示灰色提示。通道下拉菜单显示通道名称而不是编号。选中 group 时只显示由最早后代推导的只读时间和可编辑颜色，不显示事件类型或通道字段。通道可以启用、复制、重排、重命名（仅右侧通道面板提供）、编辑或删除；停用通道会取消其中事件的选择，也会阻止预览和声音。吸附器可以启用/停用、复制、重排、编辑或删除；删除吸附器会分离事件但保留解析后位置。双击行会打开编辑窗。历史最多保存 1000 条修改，并分别标记手动保存和自动保存；切换界面语言时，包括分组/解组在内的已有历史标签会立即重新翻译。

编辑细节

创建、吸附与选择

创建工具放置一次后仍保持启用；再次点击当前的 Tap、Hold、Drag、Flick 或墨点工具会退出创建模式。时间轴交互不会退出创建模式，但播放时不能创建事件。Hold 和墨点的默认时长会记住该类型上次使用的数值。吸附点距离阈值为谱面坐标 6.25。创建和附着时，边界外吸附点会被拒绝；只有数学上应恰好位于边界、却因浮点误差略微越界的点使用极小容差，其他边界判定不加容差。开放的钢笔或 Bézier 曲线中，“分段数”是区间数量，因此 3 段包含首尾端点在内会有 4 个吸附点；闭合曲线才是每段对应一个吸附点。

时间轴和主区域拖动都使用 3 像素阈值。单个可移动事件即使附着也可移动；多个附着事件只有满足附着规则时才能一起移动。Shift 拖动使用最后选中的事件作为移动上下文，因此指针下的其他事件不会被误选。停用通道不能选择、设为当前或成为拖动目标。

普通事件选择在待变换边界框宽度或高度为零时不能启动自由变换；选中 group 时会对零宽或零高方向使用 1 单位的最小边界，因此竖直或水平排列的 group 仍可旋转、缩放和移动。十字锚点初始位于边界框中心，可拖到事件、边界框角点、边缘中心、边界框中心、启用吸附器的吸附点或任意自由位置。吸附在待变换内容上的锚点会随变换移动；自由位置或吸附器上的锚点保持固定。按住 Ctrl 拖动角点会保持宽高比；按住 Shift 拖动角点或边缘手柄会以锚点为固定点；按住 Ctrl 旋转会吸附到 pi/4 的整数倍。除角点手柄外，还提供四个边缘手柄。平移或缩放超出谱面边界时会贴到边界；旋转若会超界仍被拒绝。在检查器编辑变换矩阵时，Enter 只提交该矩阵元素，不会结束自由变换。

通道与吸附器

通道行提供显示、复制、重排、编辑和删除；通道菜单不再重复提供“重命名”，应使用右侧通道行的编辑按钮或双击该行。吸附器行提供启用/停用、复制、重排、编辑和删除。吸附器编辑窗包含名称、颜色、类型参数和六数字变换矩阵，按 CSS/Canvas 惯例排成 a c tx / b d ty。矩阵改变会一致地移动附着事件、Flick 方向和游标出现位置。没有事件选择时，也可以变换已选吸附器。

游标检查器

inherit 继承前一条引导，chain 开始引导，drop 创建单事件引导，none 停止引导。出现位置可以是绝对或相对，出现时间可以用秒或拍。inherit 与 none 会隐藏除生成类型外的全部游标字段；从 inherit 改为 chain/drop 时，若原先有继承参数则填入，否则用默认值。只有 chain/drop 能编辑这些控件。绝对模式显示坐标（有吸附器时还有附着），相对模式显示距离和方向，不适用的输入行会隐藏。相对方向在数据中用弧度，输入时默认度数，勾选弧度可直接输入弧度。sviber 中只有 Tap、Hold、Drag、Flick 可连接游标，墨点不能连接。

Sunniesnow 游标导入

导入每条 tipPoint 链时，会过滤不兼容记录但不从谱面删除它们，补齐并整理占位符，寻找链区间内第一个空闲通道（必要时创建），再设置 drop 或 chain/inherit 模式，并根据占位符推导首事件的相对距离、方向和时间。没有游标的事件放在第一通道并设为 none。

播放

正向与反向播放

正向播放按谱面定时播放音乐、音符音效、命中特效以及启用时的恒定音色节拍器。音乐停止时命中特效立即消失。反向播放让时间倒退、音乐静音，但仍可播放音符音效和节拍器，不播放命中特效。停用通道不会参与播放。

A-B 循环

两个标记中较早者为 A、较晚者为 B。正向播放到 B 时无可感知空隙地回到 A；反向播放到 A 时回到 B。边界音符和节拍器每轮只调度一次。循环跳转使当前时间离开可见范围时，若未锁定则以最小幅度移动范围。

播放设置与寻拍

播放中寻拍只在交互期间暂停，并按原方向恢复；改变可见范围不会中断播放。播放结束/暂停时默认吸附到最近细分；勾选“播放后返回”则恢复开始时的时间和可见范围。锁定可见范围阻止跟随以及菜单/普通滚轮寻拍导致的范围移动，但不阻止滚动条、Ctrl+滚轮或键盘范围命令。

bgNote(location,duration=0,text="")、bigText(duration,text="")，以及 grid(duration)、diamondGrid(duration)、hexagon(duration)、checkerboard(duration)、pentagon(duration)、turntable(duration)、hexagram(duration)bg_note、big_text、diamond_grid 及其他 snake_case 对应名在当前时间和通道创建背景事件。bgNote/bg_note 的 duration 位置只有一个字符串时，会把它判断为 text。
g(events,color) 或 g(color,callback)g(events,color) 或 g(color) { ... }把指定/回调中新建的事件移入 group 并返回 group。

数据与偏好

编辑器字段

可编辑的 editor 状态保存时间吸附、细分、当前时间/通道、可见范围、通道滚动位置、播放速度、按难度保存的 allowOutOfBound、分组/背景事件/游标显示开关、mainFieldPanX、mainFieldPanY、mainFieldZoom、lockVisibleRange、playSe、seekBackAfterPlaying、metronome、readOnly 以及零到两个有理数 abLoopMarks；timing 对象在 BPM 变化之外还保存 barLines。有理数输入由整数 + 分子/分母组成；离开整个输入组后才校验，要求分母为正、分数最简且分子小于分母。

偏好、语言与外观

偏好是全局设置，不产生谱面历史。可设置浅色、深色或跟随系统主题、界面语言、音符速度、音效音量、音乐音量、NW.js 实时托管地址/端口和自动保存秒数。音效和音乐音量使用滑块与数值输出，默认均为 1；自动保存默认 120 秒，设为 0 可关闭。中文界面显示“简体中文”和“英文”，英文界面显示“Simplified Chinese”和“English”。按难度保存的“允许事件超界”不属于全局偏好。

主编辑器、宏页面和手册页面共享已保存主题。明确选择深色或浅色时优先于系统设置；选择跟随系统时才根据操作系统明暗变化。手册的语言选择会单独记住。切换编辑器语言时，已有历史标签和页脚的 JavaScript 许可信息链接也会立即更新。网页编辑器可以安装为 PWA，Service Worker 会缓存两个 JSON 翻译文件和状态图标。

保存数据

可编辑 JSON 在 sviber 扩展中保存定时、通道、吸附器、事件和编辑器状态。Group 记录包含递归子事件、位置/附着数据和颜色，但不包含 time 或 channel。普通保存还会写入供 Sunniesnow 使用的顶层 events 列表；停用通道的事件和仅供编辑的注释不会进入该列表，group 会递归展开。自动保存刻意省略生成列表。导出的关卡只包含 sviber 支持的 Sunniesnow 数据。

故障排查

音频失败时先重新载入并查看警告区；桌面构建包含音频解码器，安装后可离线运行。Monaco 加载失败时宏窗口会降级到纯文本编辑器。若打开已保存谱面后时间轴范围不对，请确认修改范围后确实保存过。遇到渲染、定时或宏问题，请在浏览器和 NW.js 都复现，导出谱面，并在问题报告中附上“帮助 > 关于”信息和导入警告。
