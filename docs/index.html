sviber

sviber User Manual

sviber is a desktop-style editor for Sunniesnow charts. The editable chart contains the timing map, events, channels, snappees, comments, and editor settings. Export generates Sunniesnow-compatible events; editor-only information is kept in the Sviber extension.

Start Here

Projects, charts, and files

In NW.js, File > New project... or Open project folder... manages a folder containing a project manifest, one JSON file per difficulty, and shared music/background files. The browser opens individual JSON charts and can save them with a download. Project-only commands are desktop-only. New chart... resets the current chart after the unsaved-change prompt.

Save writes the editable Sviber data and regenerates Sunniesnow events. Save as... chooses a new chart file. Save project writes every difficulty and shared asset. Export level... creates a Sunniesnow level package. Clipboard commands use the Sviber JSON representation, while Import chart/level file... accepts Sunniesnow JSON or a level package and reports omitted data in the warning area.

Music and timing

Set music from File > Set music.... Chart time is converted by the offset, initial BPM, and ordered BPM changes in chart properties. Beat zero may be before or after the audio beginning. The waveform is an overview of the decoded audio; loading no music still permits synthetic-time playback of note SE and the metronome.

Saving and recovery

Autosave stores a local recovery snapshot only when chart data changes. At startup, newer recoveries are offered before the last document is reopened. A save icon or autosave icon beside a History entry identifies the corresponding operation. Playback position, visible range, and the four status checkboxes are editor state and are serialized with the chart.

Workspace

Timeline anatomy

The timeline has a waveform, beat lines, channel lanes, and a horizontal overview scrollbar. The yellow line is current time. Green end handles change the visible range; the green middle bar moves it. The current time may be outside the visible range. The scrollbar's yellow line, green range, and blue A-B marks are drawn in a fixed order; blue marks are indicators only and cannot be dragged.

Ordinary wheel movement seeks by one subdivision. Ctrl+wheel changes the visible range; Shift+wheel scrolls the channel lanes. A three-pixel pointer threshold is used before event dragging or rectangular selection begins, so a click remains a click. PageUp shifts the visible range backward (negative time) and PageDown shifts it forward (positive time). Selecting a channel with Alt+Up/Down or Alt+1..9/Alt+0 reveals it when the lane scrollbar is present. Alt+1 means the first channel in the actual channel list, including inactive entries; an inactive target is not selected.

Waveform and beat lines

Click or drag the waveform to seek. Integer beats have labels; fractional beat lines use the current subdivision. A single A-B mark is a bright blue line. Two marks add a translucent blue waveform rectangle and blue lines even when the subdivision is different. BPM changes are shown as purple numbers in the waveform.

Status panel

The status panel has no title. It shows time to three decimal places, the current beat, playback speed, comments active at the current time, and the current operation. Its checkboxes are:

  • Lock visible range: playback, reverse playback, seeking, and wheel navigation do not follow or resize the range. The scrollbar and keyboard range commands remain usable.
  • SE: globally enables note hit sounds. Events in inactive channels are always silent.
  • Seek back after playing: restores the time and visible range captured when playback began.
  • Metronome: schedules a short synthesized click at every beat, with an accented first beat of each four-beat group.

Main editor field

The main field previews Sunniesnow animation at the current time. Click an event to select it without changing time. Drag a movable event to change position. Ctrl-drag copies; Alt-click removes from selection. Shift-drag or Shift-click selects a time/channel range. A selected snappee can be transformed even when no event is selected. Escape cancels a free transform; Enter applies it.

Editing Details

Creation and selection

Creation tools remain active after each placement. Timeline interaction does not exit creation mode, although events cannot be created while playback is running. Undo and redo preserve a creation tool when the history entry belongs to that mode. A hold or background-note duration defaults to the last duration used for that type.

Timeline event dragging and box selection use the three-pixel threshold. A selected movable event may move freely when it is the only movable event, even if it is attached; multiple attached events can move together only when their attachment rules permit it. Inactive channels cannot be selected, made current, or dragged into.

Channels and snappees panels

Each channel row has visibility, duplicate, up, down, edit, and delete actions. Each snappee row has activate/deactivate, duplicate, up, down, edit, and delete actions. Double-clicking a row is equivalent to Edit. Reordering changes list order only; deleting a snappee detaches events while preserving their resolved positions.

Snappee edit forms include name, color, type-specific parameters, and the six-number transformation matrix [a,b,c,d,tx,ty]. The same matrix fields appear when a new mesh or curve is created. Matrix changes are affine transforms; attached event positions, flick directions, and tip-point spawn positions are transformed consistently.

Tip-point inspector

inherit continues the previous guide, chain starts a guide, drop starts a one-event guide, and none stops a guide. Spawn position (absolute or relative), distance/direction, attached snap point, and spawn time are editable only for chain and drop; all those controls are visibly disabled for other modes. Relative direction is in radians in the data and can be entered in degrees unless the radians checkbox is selected.

Sunniesnow tip-point import

Import follows this exact sequence for every tipPoint chain:

  1. Remove incompatible records (including background notes) from the chain without removing those events from the chart.
  2. Add a placeholder at the first event's position/time if the chain has none.
  3. Remove leading placeholders repeatedly until the next record is a real compatible event; abandon a chain that has no second record.
  4. Keep only the first placeholder.
  5. Find the first channel with no occupied event from the second through last chain event, inclusive; create a channel if necessary, then place all real chain events there.
  6. Set one real event to drop, or the first to chain and the rest to inherit.
  7. Set the first event's relative distance, direction, and seconds-based spawn time from the placeholder to that event. Events without a tip point are put in the first channel with mode none.

Playback

Forward and reverse playback

Forward playback schedules WebAudio note sounds and visual hit effects ahead of wall-clock time. Reverse playback uses a synthetic clock, schedules note SE in descending time order, and never triggers stage hit effects. The music buffer itself is not played in reverse. Inactive channels never contribute to either schedule.

A-B looping

With two marks, the earlier mark is A and the later is B. Forward playback uses a WebAudio source with loopStart/loopEnd so the audio transition has no inserted gap; reverse playback wraps from A to B on the synthetic clock. Notes and metronome clicks at the loop boundary are not scheduled twice. If the wrap leaves the current visible range, the range moves by the minimum amount unless it is locked.

Playback settings and seeking

Seeking while playing pauses only for the interaction and resumes in the same direction. Changing the visible range never interrupts playback. When playback ends or is paused, time snaps to the nearest subdivision unless Seek back after playing is enabled, in which case the captured time and visible range are restored. Lock visible range prevents follow mode and seek-induced range movement but does not prevent scrollbar or keyboard range commands.

Macros Interface

Lists and tabs

The macro window has File, Edit, and Run menus, Global and Project tabs, an editor tab strip, and a console. Global macros are stored in localStorage. Project macros are .js files in the open NW.js project directory; the Project tab is disabled in a browser or when no project is open. Clicking a list item opens or activates a tab. An asterisk means unsaved editor text; the tab close button asks before discarding it.

Data and Preferences

Editor fields

The Sviber editor object stores lockVisibleRange, playSe, seekBackAfterPlaying, metronome, and zero, one, or two rational abLoopMarks in addition to time, subdivision, range, speed, current channel, and out-of-bounds settings. Rational inputs are integer + numerator/denominator controls. Validation waits until focus leaves the whole three-input group, then requires a positive denominator, a reduced fraction, and a numerator smaller than the denominator.

Preferences and appearance

Preferences choose light/dark/system theme, interface language, note speed, and whether placement may leave chart bounds. Theme and language default from the operating system and are stored globally; changing them does not create chart history. Documentation uses the same language selector and independently follows prefers-color-scheme.

Troubleshooting

If audio fails, check the complete decoder error chain in the developer console and verify that the packaged decoder bundle exists. If Monaco cannot load, the macro window deliberately falls back to a plain text editor. For rendering or timing bugs, reproduce in both browser and NW.js, export the chart, and include Help > About runtime information and the import warning text in an issue.

sviber 用户手册

sviber 是 Sunniesnow 谱面的桌面式编辑器。可编辑数据包含定时表、事件、通道、吸附器、注释和编辑器设置；导出时生成 Sunniesnow 事件，编辑器专用信息保留在 Sviber 扩展中。

从这里开始

工程、谱面与文件

NW.js 中，“文件 > 新建工程...”或“打开工程文件夹...”管理工程目录，其中有工程清单、每个难度一个 JSON 文件以及共享音乐/背景文件。浏览器可打开单个 JSON 谱面并下载保存；无法访问文件夹时，工程命令为桌面专用。“新建谱面...”会在未保存提示后重置当前谱面。

“保存”写入当前已知路径，“另存为...”选择新路径，“保存工程”写入全部难度和共享资源，“导出关卡...”生成 Sunniesnow 关卡包。剪贴板命令使用 Sviber JSON；“导入谱面/关卡文件...”接受 Sunniesnow JSON 或关卡包，并在警告中说明被省略的数据。

音乐与定时

通过“文件 > 设置音乐...”载入音频。谱面时间由偏移、初始 BPM 和按顺序排列的 BPM 变化换算；第零拍可以早于或晚于音频起点。波形显示已解码音频概览；没有音乐时仍可用合成时间播放音符 SE 和节拍器。

保存与恢复

只有谱面数据发生变化时才会自动保存到本地恢复快照。启动时会先提供较新的恢复记录，再尝试打开上次文档。历史记录旁的保存/自动保存图标标识对应操作。播放位置、可见范围和状态栏四个复选框属于编辑器状态，也会随谱面序列化。

工作区

时间轴结构

时间轴包含波形、拍线、通道轨道和横向总览滚动条。黄色线是当前时间，绿色两端调整可见范围，绿色中段平移范围。当前时间可以在可见范围外。滚动条中的黄色线、绿色范围和蓝色 A-B 标记按固定优先级绘制；蓝色标记只是指示，不能拖动。

普通滚轮按一个细分寻拍；Ctrl+滚轮改变可见范围；Shift+滚轮滚动通道。开始拖动事件或框选前必须超过 3 像素，因此单击不会误拖。PageUp 将可见范围向负时间移动，PageDown 向正时间移动。Alt+上/下或 Alt+1..9/Alt+0 选择通道并在有通道滚动条时自动显示。Alt+1 指实际通道列表第一项（包括停用通道）；目标停用时不会切换。

波形与拍线

点击或拖动波形寻拍；整数拍有数字，分数拍线使用当前细分。一个 A-B 标记显示亮蓝竖线；两个标记额外在波形覆盖半透明蓝色矩形，并且无论当前细分都显示蓝线。BPM 变化以紫色数字显示。

状态栏

状态栏没有标题，显示三位小数时间、当前拍、播放速度、当前时间生效的注释和操作信息。四个复选框如下：

  • 锁定可见范围：播放、反向播放、寻拍和滚轮不会跟随或改变范围；滚动条和键盘范围命令仍可用。
  • SE：全局启用音符打击音；停用通道始终静音。
  • 播放后返回：恢复播放开始时记录的时间和可见范围。
  • 节拍器：每拍播放短促合成点击音，每四拍的第一拍加重。

主编辑区域

主区域按当前时间预览 Sunniesnow 动画。点击事件选择而不改变时间；拖动可移动事件改变位置，Ctrl 拖动复制，Alt 点击移出选择。Shift 拖动或点击选择时间/通道范围。没有事件选择时也可以变换一个已选择的吸附器。Esc 取消自由变换，Enter 应用自由变换。

菜单参考

编辑细节

创建与选择

创建工具放置一次后仍保持启用。时间轴交互不会退出创建模式，但播放时不能创建事件；属于创建模式的历史记录撤销/重做后仍保持工具。Hold 和背景音符的默认时长是该类型上次使用的时长。

时间轴拖事件和框选都使用 3 像素阈值。单个可移动事件即使附着也可移动；多个附着事件只有满足附着规则时才能一起移动。停用通道不能选择、设为当前或成为拖动目标。

通道与吸附器面板

每个通道行都有显示、复制、上移、下移、编辑和删除按钮；每个吸附器行都有启用/停用、复制、上下移、编辑和删除按钮。双击等同于编辑。重排只改变列表顺序；删除吸附器会分离事件并保留解析后位置。

吸附器编辑窗包含名称、颜色、类型参数和六数字变换矩阵 [a,b,c,d,tx,ty]；新建网格/曲线时也可输入矩阵。矩阵改变是仿射变换，附着事件位置、Flick 方向和 Tip point 出现位置保持一致。

Tip point 检查器

inherit 继承前一条引导，chain 开始引导，drop 创建单事件引导，none 停止引导。只有 chain/drop 能编辑出现位置、距离/方向、附着点和出现时间；其他模式下这些控件全部禁用。相对方向在数据中用弧度，输入时默认度数，勾选弧度可直接输入弧度。

Sunniesnow Tip point 导入

每个 tipPoint 链严格执行以下七步：

  1. 从链中移除不兼容记录（包括背景音符），但不从谱面删除这些事件。
  2. 链首不是占位符时，在首事件位置/时间添加占位符。
  3. 反复删除开头占位符，直到第二项是兼容真实事件；没有第二项则放弃该链。
  4. 只保留第一个占位符。
  5. 寻找从第二项到最后一项（含边界）都没有事件占用的第一个通道；找不到则新建通道，然后把真实链事件放入其中。
  6. 只有一个真实事件时设为 drop，否则首项设 chain、其余设 inherit。
  7. 根据占位符到首事件的相对位置和时间设置距离、方向及秒制出现时间。没有 tip point 的事件放在第一通道并设为 none。

播放

正向与反向播放

正向播放提前调度 WebAudio 音符声和舞台命中特效；反向播放使用合成时钟按递减时间调度音符 SE，绝不触发舞台命中特效，音乐缓冲区本身不会反向播放。停用通道不会参与任何调度。

A-B 循环

两个标记中较早者为 A、较晚者为 B。正向播放使用 WebAudio 的 loopStart/loopEnd，切换不插入空隙；反向播放在合成时钟到达 A 时跳到 B。边界音符和节拍器不会重复调度。循环跳转使当前时间离开可见范围时，若未锁定则以最小幅度移动范围。

播放设置与寻拍

播放中寻拍只在交互期间暂停，并按原方向恢复；改变可见范围不会中断播放。播放结束/暂停时默认吸附到最近细分；勾选“播放后返回”则恢复开始时的时间和可见范围。锁定可见范围阻止跟随和寻拍导致的范围移动，但不阻止滚动条或键盘范围命令。

宏界面

列表与标签

宏窗口有文件、编辑、运行菜单，全局/工程标签，编辑器标签栏和控制台。全局宏存于 localStorage；工程宏是打开的 NW.js 工程目录中的 .js 文件。浏览器或未打开工程时工程标签禁用。点击列表项目打开/切换标签；星号表示未保存，关闭标签前会询问。

宏文件命令

命令快捷键作用

宏 API

沙箱接收深拷贝的 state，同时以 state/chart 和 api 提供。便捷函数既是顶层名称也是 api 成员：

API用途
tap/t、hold/h、drag/d、flick/f、bgNote按当前时间/通道添加事件，可传坐标、时长、角度和 tip 字段覆盖值。
event(type, overrides)添加任意支持的事件。
channel(name)/addChannel添加通道。
snappee(type, overrides)/addSnappee添加网格或曲线，状态检查时补齐默认参数。
select(...ids)替换事件选择并返回所选事件。
setTime(value)用有理数元组或数字秒数设置时间。
console.log/info/warn/error、log把可 JSON 化的值写入宏控制台。

主窗口用 ChartModel 检查返回状态、限制大小、同步元数据/媒体并记录一条历史；异常或无效状态只显示在控制台，不会应用。

数据与偏好

编辑器字段

Sviber 的 editor 对象除时间、细分、范围、速度、当前通道和超界设置外，还保存 lockVisibleRange、playSe、seekBackAfterPlaying、metronome 以及零到两个有理数 abLoopMarks。有理数输入由整数 + 分子/分母组成；离开整个三输入组后才校验，要求分母为正、分数最简且分子小于分母。

偏好与外观

偏好可选择浅色/深色/跟随系统主题、界面语言、音符速度及是否允许越过谱面边界。主题和语言默认取系统并全局保存；修改不产生谱面历史。文档页有独立语言选择，并按 prefers-color-scheme 自动明暗。

故障排查

音频失败时在开发者控制台查看完整解码器错误链，并确认打包版包含 decoder bundle。Monaco 加载失败时宏窗口会降级到纯文本编辑器。渲染或定时问题请在浏览器和 NW.js 都复现，导出谱面，并在问题报告中附上“帮助 > 关于”的运行时信息和导入警告。
