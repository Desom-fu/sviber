sviber

sviber User Manual

sviber is a desktop-style editor for Sunniesnow charts. A chart contains timing, events, channels, snappees, comments, media references, and editor state. Saving a chart keeps the editable data; exporting a level produces Sunniesnow-compatible chart data. The web version is an installable PWA and caches its application shell and translations for offline startup.

Start Here

Projects, charts, and files

In NW.js, File > New project... and Open project folder... manage a folder with a project manifest, one JSON file per difficulty, and shared music/background files. A browser opens one JSON chart at a time and saves it with a download. Project-only commands are unavailable in a browser. New chart... asks about unsaved changes before replacing the current chart.

Save writes the editable chart, while Save as... chooses a new file. Save project writes every difficulty and shared asset. Export level... creates a Sunniesnow level package. Clipboard commands use the editable sviber JSON; Import chart/level file... accepts editable JSON, plain Sunniesnow JSON, or a level package and reports omitted data in the warning area.

Difficulties and new charts

The NW.js toolbar has a difficulty selector. Each option is shown as difficulty name rating superscript; the difficulty name uses its configured color. Switching difficulties asks whether to save pending changes. The selector is not shown in the browser, where only one chart is open. A new chart starts with an active rectangular Playfield grid from (-100,50) to (100,-50), divided into 16 by 8 tiles. Other preset snappees can be added later.

Music and timing

Set music from File > Set music.... The offset is the audio time of beat zero; the initial BPM and ordered BPM changes convert beat positions to seconds. Beat zero can be before or after the audio beginning. Opening a saved chart restores its saved current time, subdivision, and visible timeline range.

Saving and recovery

By default, a dirty chart is saved to the local recovery list every 120 seconds. The interval is configurable; zero disables autosave. Startup offers every recovery newer than the last manual save before reopening the last document. Autosave records omit the generated top-level event list to reduce storage; ordinary chart and project saves include it. History entries distinguish manual saves from autosaves.

Workspace

Layout and panel buttons

The workspace has a menu bar, toolbar, timeline, status panel, scroll view, main editor field, side panels, history, and a tooltip bar. Hover near the left edge of the main editor field to reveal a DOM button that hides or shows the scroll view. Hover near the right edge to reveal a button that hides or shows the Inspector, Channels, Snappees, and History panels together. Neither group is hidden by default; hiding either group gives the main field more width.

Timeline anatomy

The timeline contains a waveform, beat lines, channel lanes, and a horizontal overview scrollbar. The yellow line is current time. Green end handles change the visible range; the green middle bar moves both ends. The current time may be outside the visible range. On the scrollbar, the yellow current-time line has priority over the green handles and bar; blue A-B marks are indicators only and cannot be dragged.

Clicking a lane seeks to its time and makes that lane current. Clicking and dragging on an empty lane makes a live rectangular selection; a three-pixel movement threshold keeps a click from becoming a drag. Ctrl adds to selection and Alt removes from selection. Shift-click or Shift-drag selects an inclusive channel range and a time range whose end is exclusive. Dragging an event moves it in time; dragging its white duration handle changes its end time.

Ordinary wheel movement seeks by one subdivision. Ctrl+wheel zooms the visible range without changing its center; Shift+wheel scrolls channel lanes. Clicking outside the range bar pages the range by one span. PageUp shifts the range toward negative time and PageDown toward positive time. When a channel is selected with Alt+Up/Down or Alt+1..9/Alt+0, the lane scrollbar follows it when needed. Number and Space shortcuts remain active when a status checkbox or the difficulty selector has focus.

Waveform and beat lines

Click or drag the waveform to seek. Integer beats have labels; fractional beat lines use the current subdivision. One A-B mark is a bright blue line. Two marks add a translucent blue interval and two blue lines even when the subdivision differs. BPM changes are shown as purple numbers. Seeking while stopped snaps to the nearest subdivision except when a command explicitly requests an exact time.

Status panel

The status panel has no title. It shows time to three decimal places, the current beat using the current subdivision denominator, playback speed, comments active at the current time, and the current operation. A selected comment is red here; other comments use the normal text color. Its six checkboxes use icons without visible text labels:

  • Lock visible range: playback, reverse playback, and menu/mouse-wheel seeking do not follow or resize the range. The scrollbar, Ctrl+wheel, and keyboard range commands remain usable.
  • SE: globally enables note hit sounds. Events in inactive channels are always silent.
  • Seek back after playing: restores the time and visible range captured when playback began.
  • Metronome: plays one sharp, short synthesized click at every beat. Every beat uses the same sound and level; there is no strong-beat/weak-beat accent. Its level follows the Preferences SE volume.
  • Read-only: keeps event selection, time/range navigation, Music commands, and comment manipulation available while disabling chart, snappee, channel, history, and macro changes. The macro window remains available; global macros stay editable, project macros become read-only, and no macro can run.
  • Fullscreen: enters or leaves fullscreen. F11 toggles it even while a popup form is active, and the checkbox follows fullscreen changes made by the runtime. In NW.js, Esc does not leave fullscreen.

Main editor field

The main field previews the chart at the current time. Background patterns and big text are not selected by clicking their preview; select them from the timeline or Channels panel. Click an event to select it without changing time; Ctrl-click adds it and Alt-click removes it. Selected objects remain visibly marked even when outside the current preview time. Inactive channels and their tip points are hidden and cannot be selected.

Drag a movable event to change position. A single event can attach automatically to the nearest active snap point; attached events can be moved according to their snappee type. Shift-drag moves the current selection without requiring the pointer to hit one selected event and without retargeting another event. If no movable event is selected, the same gesture moves the selected snappee; any of its snap points can align to a nearby point on another active snappee. Escape cancels a free transform and Enter applies it.

Scroll view

The scroll view is to the left of the main field. Horizontal position is chart x; vertical position is time, with later time higher. The current time stays at a fixed line near the bottom while events move through it. Hold and background-note durations have vertical tails. Inactive-channel events are hidden. Background-note icons are drawn below other event icons; among other icons, later times are drawn above earlier times. Tip-point chains use a translucent white connector, and a thin dark-yellow segment at the first event shows the spawn direction. Each connector is drawn only for an adjacent pair in the same guide with at least one visible endpoint, so unrelated off-screen notes cannot create a full-width line.

The scroll view uses the same pixels-per-second scale vertically as the timeline uses horizontally; its horizontal chart-x scale remains independent. Its visible time span can therefore extend beyond the music. Horizontal beat lines use the timeline colors, the current time is a bright yellow line, and red labels mark integer beats. Click an icon to select it; Ctrl adds and Alt removes. Drag on empty space to box-select by event centers. The scroll view never edits event positions or times.

Inspector, Channels, Snappees, and History

The Inspector shows common properties of the selected events and shows a gray message when nothing is selected. Channels can be activated, duplicated, reordered, renamed from the right-side Channels panel, edited, or deleted; deactivating a channel deselects its events and prevents their preview and sound. Snappees can be activated, duplicated, reordered, edited, or deleted; deleting one detaches its events while keeping their resolved positions. Double-clicking a row opens its edit form. History stores up to 1000 changes and marks manual and automatic saves separately.

Editing Details

Creation, snapping, and selection

Creation tools remain active after each placement. Timeline interaction does not exit creation mode, although events cannot be created while playback is running. Hold and background-note duration defaults remember the last value used for that type. Snap-to-point uses a chart-coordinate distance threshold of 6.125. During creation and attachment, points outside the chart boundary are rejected; only a tiny numeric tolerance is used for points that should mathematically lie exactly on the boundary. Other in/out-of-bounds checks have no tolerance. For an open Pen or Bezier curve, the segment count is the number of intervals, so three segments have four snap points including both endpoints; a closed curve has one snap point per segment.

Timeline and stage dragging use a three-pixel pointer threshold. A selected movable event may move freely when it is the only movable event, even if it is attached; multiple attached events move together only when their attachment rules allow it. Shift-dragging uses the last selected event as the movement context, so another event under the pointer cannot be selected accidentally. Inactive channels cannot be selected, made current, or dragged into.

Channels and snappees

Channel rows provide visibility, duplicate, reorder, edit, and delete actions; the channel menu no longer contains a duplicate Rename command, so renaming is available from the right-side row action or by double-clicking that row. Snappee rows provide activate/deactivate, duplicate, reorder, edit, and delete actions. Snappee edit forms include name, color, type-specific parameters, and a six-number transformation matrix [a,b,c,d,tx,ty]. Matrix changes move attached event positions, flick directions, and tip-point spawn positions consistently. A selected snappee can be translated or transformed even when no events are selected.

Tip-point inspector

inherit continues the previous guide, chain starts a guide, drop starts a one-event guide, and none stops a guide. Spawn position can be absolute or relative; spawn time can be seconds or beats. Only chain and drop enable these controls. Relative direction is stored in radians and is entered in degrees unless the radians option is selected. Only tap, hold, drag, and flick are tip-pointable in sviber; background notes are not.

Sunniesnow tip-point import

Import filters incompatible records from each tipPoint chain without deleting those events from the chart, adds and trims placeholders, chooses the first channel free for the chain interval (creating one when needed), and assigns drop or chain/inherit modes. It derives the first event's relative spawn distance, direction, and time from the placeholder. Events with no tip point go to the first channel with mode none.

Playback

Forward and reverse playback

Forward playback follows the chart timing and plays music, note sounds, hit effects, and the constant-tone metronome when enabled. Reverse playback moves time backward, leaves music muted, and can still play note sounds and metronome clicks; it does not play hit effects. Inactive channels never contribute to playback.

A-B looping

With two marks, the earlier mark is A and the later mark is B. Forward playback returns to A at B without an audible gap; reverse playback returns to B at A. Boundary notes and metronome clicks are scheduled once per pass. If a loop jump leaves the visible range, the range moves by the minimum amount unless it is locked.

Playback settings and seeking

Seeking while playing pauses only for the interaction and resumes in the same direction. Changing the visible range never interrupts playback. When playback ends or is paused, time snaps to the nearest subdivision unless Seek back after playing is enabled, in which case the captured time and visible range are restored. Lock visible range prevents follow mode and menu/mouse-wheel seeking from moving the range, but not scrollbar, Ctrl+wheel, or keyboard range commands.

Macros Interface

Lists and tabs

The macro window has File, Edit, and Run menus, Global and Project lists, an editor tab strip, and a console. A macro is JavaScript or Ruby. Global macros are stored by sviber; project macros are .js or .rb files in the open NW.js project directory. The Project list is unavailable in a browser or without an open project. An asterisk means unsaved editor text; closing a dirty tab asks before discarding it. While the main editor is read-only, global macros remain editable, project editing controls are disabled, and both F8 and Run are disabled.

Data and Preferences

Editor fields

The editable editor state stores time snapping, subdivision, current time/channel, visible range, playback speed, out-of-bounds permission, lockVisibleRange, playSe, seekBackAfterPlaying, metronome, readOnly, and zero, one, or two rational abLoopMarks. Rational inputs use integer + numerator/denominator controls. Validation waits until focus leaves the complete group, then requires a positive denominator, a reduced fraction, and a numerator smaller than the denominator.

Preferences, language, and appearance

Preferences are global and do not create chart history. They include Light, Dark, or System theme; interface language; note speed; SE volume; music volume; out-of-bounds placement; and autosave interval in seconds. SE and music volume default to 1 and are edited with a range slider plus a numeric output. The default autosave interval is 120 seconds, and zero disables it. Each language selector uses its current interface language: English shows Simplified Chinese, while Chinese shows 简体中文; the English choice remains English.

The main editor, macro page, and manual share the saved theme. Explicit Dark or Light always wins; System follows the operating-system color preference. The language choice is remembered separately for the manual. The web editor can be installed as a PWA; its Service Worker caches both JSON translation files and the icon controls.

Saved data

An editable JSON chart keeps the sviber extension with timing, channels, snappees, events, and editor state. A normal save also writes a generated top-level events list for Sunniesnow compatibility; inactive-channel events and editor-only comments are omitted from that generated list. Autosave intentionally leaves that generated list out. Exported level charts contain only the supported Sunniesnow data.

Troubleshooting

If audio fails, reload once and check the warning area; a desktop build includes its audio decoder and can run offline after installation. If Monaco cannot load, the macro window falls back to a plain text editor. If a saved chart opens with an unexpected timeline, verify that it was saved after the desired range was set. For rendering, timing, or macro bugs, reproduce in both browser and NW.js, export the chart, and include Help > About information and import warnings in an issue.

sviber 用户手册

sviber 是 Sunniesnow 谱面的桌面式编辑器。谱面包含定时、事件、通道、吸附器、注释、媒体引用和编辑器状态；保存会保留可编辑数据，导出关卡时才生成 Sunniesnow 可用的谱面数据。网页版本可以安装为 PWA，Service Worker 会缓存应用外壳和翻译文件，便于离线启动。

从这里开始

工程、谱面与文件

NW.js 中，“文件 > 新建工程...”和“打开工程文件夹...”管理包含工程清单、每个难度一个 JSON 以及共享音乐/背景文件的文件夹。浏览器一次打开一个 JSON 谱面并用下载保存；浏览器不能使用工程专用命令。“新建谱面...”会先处理未保存修改，再替换当前谱面。

“保存”写入可编辑谱面，“另存为...”选择新文件；“保存工程”写入全部难度和共享资源；“导出关卡...”生成 Sunniesnow 关卡包。剪贴板命令使用可编辑 Sviber JSON；“导入谱面/关卡文件...”接受可编辑 JSON、普通 Sunniesnow JSON 或关卡包，并在警告区说明省略的数据。

难度与新谱面

NW.js 工具栏有难度选择器。每个选项显示为“难度名 定级 上标”，难度名使用设置的颜色。切换难度时会询问是否保存未保存修改；浏览器不显示选择器，因为一次只打开一个谱面。新谱面默认创建并启用一个从 (-100,50) 到 (100,-50)、横向 16 格纵向 8 格的“游玩区域网格”；其他预设吸附器可稍后添加。

音乐与定时

通过“文件 > 设置音乐...”载入音频。偏移表示第零拍对应的音频时间；初始 BPM 和按顺序排列的 BPM 变化把拍位换算成秒。第零拍可以早于或晚于音频起点。打开已保存谱面时，会恢复保存时的当前时间、细分和时间轴可见范围。

保存与恢复

默认情况下，有未保存修改的谱面每 120 秒写入一次本地恢复记录。间隔可修改，设为 0 可关闭自动保存。启动时会列出所有晚于最后一次手动保存的恢复记录，然后再尝试打开上次文档。自动保存为了节省空间不写入生成的顶层事件列表；普通谱面保存和工程保存仍会写入。历史记录会区分手动保存和自动保存。

工作区

布局与面板按钮

工作区包含菜单栏、工具栏、时间轴、状态栏、滚动视图、主编辑区域、侧面板、历史面板和提示栏。鼠标移到主编辑区域左边缘中央会出现 DOM 按钮，用来隐藏或显示滚动视图；移到右边缘中央会出现按钮，用来同时隐藏或显示检查器、通道、吸附器和历史面板。两组面板默认显示，隐藏后主编辑区域会变宽。

时间轴结构

时间轴包含波形、拍线、通道轨道和横向总览滚动条。黄色线是当前时间；绿色两端调整可见范围，绿色中段同时平移两端；当前时间可以在可见范围外。滚动条上的黄色当前时间线优先于绿色端点和中段；蓝色 A-B 标记只是指示，不能拖动。

点击轨道会寻拍并切换当前通道；在空轨道按下并拖动会实时框选，超过 3 像素才从点击变为拖动。Ctrl 追加选择，Alt 移除选择。Shift 点击或拖动选择包含首尾通道的范围，以及起点包含、终点不包含的时间范围。拖动事件会移动拍位，拖动白色时长手柄会改变结束时间。

普通滚轮按一个细分寻拍；Ctrl+滚轮在不改变中心的情况下缩放可见范围；Shift+滚轮滚动通道。点击可见范围条外侧会按一个跨度翻页。PageUp 向负时间移动范围，PageDown 向正时间移动。用 Alt+上/下或 Alt+1..9/Alt+0 选择通道时，有需要会自动滚动通道条。状态栏图标控件或右上角难度选择器获得焦点时，数字键和空格等全局快捷键仍然有效。

波形与拍线

点击或拖动波形寻拍；整数拍有数字，分数拍线使用当前细分。一个 A-B 标记显示亮蓝竖线；两个标记额外显示半透明蓝色区间和两条蓝线，无论当前细分如何都可见。BPM 变化以紫色数字显示。停止时寻拍通常吸附到最近细分，明确要求精确时间的命令除外。

状态栏

状态栏没有标题，显示三位小数时间、按当前细分分母显示的当前拍、播放速度、当前时间生效的注释和操作信息。注释被选中时在这里显示为红色，否则使用普通文字颜色。六个复选框都只有图标，没有可见文字：

  • 锁定可见范围：播放、反向播放以及菜单/普通滚轮寻拍不会跟随或改变范围；滚动条、Ctrl+滚轮和键盘范围命令仍可用。
  • SE：全局启用音符打击音；停用通道始终静音。
  • 播放后返回：恢复播放开始时记录的时间和可见范围。
  • 节拍器：每拍播放一次短促、清晰的合成点击音。每拍使用相同的声音和响度，不区分强拍与弱拍；响度跟随偏好设置中的音效音量。
  • 只读：仍可选择事件、改变时间/范围、使用“音乐”菜单和操作注释，但会禁用谱面、吸附器、通道、历史和宏修改。宏窗口仍可打开；全局宏可编辑，工程宏只读，任何宏都不能运行。
  • 全屏：进入或退出全屏；即使弹窗表单打开，F11 也能切换，复选框会跟随运行时产生的全屏变化。NW.js 中 Esc 不会退出全屏。

主编辑区域

主区域按当前时间预览谱面。背景图案和大字不能通过预览点击选择，只能从时间轴或通道面板选择。点击事件选择而不改变时间；Ctrl 点击追加，Alt 点击移除。即使事件不在当前预览时间，选中标记仍会显示。停用通道及其 Tip point 不可见也不可选择。

拖动可移动事件改变位置；单个事件靠近启用吸附器的吸附点时会自动附着，附着事件可按吸附器类型移动。Shift 拖动会移动当前选择，不需要瞄准某个已选事件，也不会误选指针下的其他事件。没有可移动事件选择时，同一手势会移动已选吸附器；它的任意吸附点都可以对齐到其他启用吸附器附近的吸附点。Escape 取消自由变换，Enter 应用自由变换。

滚动视图

滚动视图位于主编辑区左侧。横向是谱面 x 坐标，纵向是时间，较晚时间在上方。当前时间固定在靠近底部的一条线上，事件相对它向上或向下移动。Hold 和背景音符显示表示时长的竖直尾巴。停用通道中的事件隐藏；背景音符图标总在其他事件下方，其他图标则较晚时间绘制在较早时间上方。Tip point 链用半透明白色粗线连接，首事件旁的深黄色细线表示出现方向；每条白线只连接同一引导中相邻且至少有一个端点可见的事件，不会因屏幕外事件把整行铺满。

滚动视图的纵向每秒像素比例与时间轴的横向每秒像素比例一致，横向谱面 x 比例独立，因此可见时间范围可能超过音乐边界。水平拍线使用与时间轴相同的颜色，当前时间是亮黄色线，整数拍左侧显示红色数字。点击图标选择；Ctrl 追加，Alt 移除；在空白处拖动按事件中心框选。滚动视图不能直接编辑事件的时间或位置。

检查器、通道、吸附器与历史

检查器显示所选事件的公共属性，没有选择时会显示灰色提示。通道可以启用、复制、重排、重命名（仅右侧通道面板提供）、编辑或删除；停用通道会取消其中事件的选择，也会阻止预览和声音。吸附器可以启用/停用、复制、重排、编辑或删除；删除吸附器会分离事件但保留解析后位置。双击行会打开编辑窗。历史最多保存 1000 条修改，并分别标记手动保存和自动保存。

编辑细节

创建、吸附与选择

创建工具放置一次后仍保持启用。时间轴交互不会退出创建模式，但播放时不能创建事件。Hold 和背景音符的默认时长会记住该类型上次使用的数值。吸附点距离阈值为谱面坐标 6.125。创建和附着时，边界外吸附点会被拒绝；只有数学上应恰好位于边界、却因浮点误差略微越界的点使用极小容差，其他边界判定不加容差。开放的钢笔或贝塞尔曲线中，“分段数”是区间数量，因此 3 段包含首尾端点在内会有 4 个吸附点；闭合曲线才是每段对应一个吸附点。

时间轴和主区域拖动都使用 3 像素阈值。单个可移动事件即使附着也可移动；多个附着事件只有满足附着规则时才能一起移动。Shift 拖动使用最后选中的事件作为移动上下文，因此指针下的其他事件不会被误选。停用通道不能选择、设为当前或成为拖动目标。

通道与吸附器

通道行提供显示、复制、重排、编辑和删除；通道菜单不再重复提供“重命名”，应使用右侧通道行的编辑按钮或双击该行。吸附器行提供启用/停用、复制、重排、编辑和删除。吸附器编辑窗包含名称、颜色、类型参数和六数字变换矩阵 [a,b,c,d,tx,ty]。矩阵改变会一致地移动附着事件、Flick 方向和 Tip point 出现位置。没有事件选择时，也可以变换已选吸附器。

Tip point 检查器

inherit 继承前一条引导，chain 开始引导，drop 创建单事件引导，none 停止引导。出现位置可以是绝对或相对，出现时间可以用秒或拍；只有 chain/drop 能编辑这些控件。相对方向在数据中用弧度，输入时默认度数，勾选弧度可直接输入弧度。sviber 中只有 Tap、Hold、Drag、Flick 可连接 Tip point，背景音符不能连接。

Sunniesnow Tip point 导入

导入每条 tipPoint 链时，会过滤不兼容记录但不从谱面删除它们，补齐并整理占位符，寻找链区间内第一个空闲通道（必要时创建），再设置 drop 或 chain/inherit 模式，并根据占位符推导首事件的相对距离、方向和时间。没有 Tip point 的事件放在第一通道并设为 none。

播放

正向与反向播放

正向播放按谱面定时播放音乐、音符音效、命中特效以及启用时的恒定音色节拍器。反向播放让时间倒退、音乐静音，但仍可播放音符音效和节拍器，不播放命中特效。停用通道不会参与播放。

A-B 循环

两个标记中较早者为 A、较晚者为 B。正向播放到 B 时无可感知空隙地回到 A；反向播放到 A 时回到 B。边界音符和节拍器每轮只调度一次。循环跳转使当前时间离开可见范围时，若未锁定则以最小幅度移动范围。

播放设置与寻拍

播放中寻拍只在交互期间暂停，并按原方向恢复；改变可见范围不会中断播放。播放结束/暂停时默认吸附到最近细分；勾选“播放后返回”则恢复开始时的时间和可见范围。锁定可见范围阻止跟随以及菜单/普通滚轮寻拍导致的范围移动，但不阻止滚动条、Ctrl+滚轮或键盘范围命令。

列表与标签

宏窗口有文件、编辑、运行菜单，全局/工程列表，编辑器标签栏和控制台。宏可以是 JavaScript 或 Ruby。全局宏由 sviber 保存；工程宏是打开的 NW.js 工程目录中的 .js 或 .rb 文件。浏览器或未打开工程时工程列表不可用。星号表示未保存；关闭脏标签前会询问。主编辑器处于只读模式时，全局宏仍可编辑，工程宏编辑控件会禁用，F8 和“运行”也会禁用。

数据与偏好

编辑器字段

可编辑的 editor 状态保存时间吸附、细分、当前时间/通道、可见范围、播放速度、超界许可、lockVisibleRange、playSe、seekBackAfterPlaying、metronome、readOnly 以及零到两个有理数 abLoopMarks。有理数输入由整数 + 分子/分母组成；离开整个输入组后才校验，要求分母为正、分数最简且分子小于分母。

偏好、语言与外观

偏好是全局设置，不产生谱面历史。可设置浅色、深色或跟随系统主题、界面语言、音符速度、音效音量、音乐音量、允许超界放置和自动保存秒数。音效和音乐音量使用滑块与数值输出，默认均为 1；自动保存默认 120 秒，设为 0 可关闭。中文界面显示“简体中文”和“英文”，英文界面显示“Simplified Chinese”和“English”。

主编辑器、宏页面和手册页面共享已保存主题。明确选择深色或浅色时优先于系统设置；选择跟随系统时才根据操作系统明暗变化。手册的语言选择会单独记住。网页编辑器可以安装为 PWA，Service Worker 会缓存两个 JSON 翻译文件和状态图标。

保存数据

可编辑 JSON 在 sviber 扩展中保存定时、通道、吸附器、事件和编辑器状态。普通保存还会写入供 Sunniesnow 使用的顶层 events 列表；停用通道的事件和仅供编辑的注释不会进入该列表。自动保存刻意省略生成列表。导出的关卡只包含 sviber 支持的 Sunniesnow 数据。

故障排查

音频失败时先重新载入并查看警告区；桌面构建包含音频解码器，安装后可离线运行。Monaco 加载失败时宏窗口会降级到纯文本编辑器。若打开已保存谱面后时间轴范围不对，请确认修改范围后确实保存过。遇到渲染、定时或宏问题，请在浏览器和 NW.js 都复现，导出谱面，并在问题报告中附上“帮助 > 关于”信息和导入警告。
